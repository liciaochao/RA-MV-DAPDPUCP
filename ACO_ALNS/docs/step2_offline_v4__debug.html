3.2 ACO 外层构造与信息素学习机制（重点）

3.2.1 ACO 整体框架

代码锚点：src/spd/aco_alns.py::ACOALNSSolver.solve、_run_single_ant、ALNSOptimizer.optimize。

角色定义：

  • ACO 是离线优化的“外层全局构造 + 学习”框架。
  • ALNS 是每只蚂蚁生成解后的“内层局部改进”框架。
  • 嵌套关系：ACO outer iteration -> ant construction -> ALNS refine -> select best -> pheromone update。

关键超参数（名称/代码变量/示例默认值）：

  • 外层迭代次数：params.aco.max_iterations，config_small=20
  • 蚂蚁数：params.aco.ant_count，config_small=5
  • 无改进提前停止：params.aco.no_improve_max，config_small=15
  • 并行开关：params.aco.parallel_ants（可选；无则默认 True，通过 monkey patch 兼容）

外层循环完整版伪代码（含分支）：

Input: instance, params, home_status(all True offline), rng
1) initial_solution <- ETPRC.build_initial_solution(...)
2) initial_objective <- compute_objective(..., beta=beta_init)
3) initialize pheromone dict
4) state.best <- initial_solution
5) for aco_iteration in [1..max_iterations]:
     a) build ant_args for ant_count ants
     b) if parallel pool exists:
          run pool.map(_run_single_ant)
        else:
          serial run _run_single_ant
     c) for each ant_result:
          skip if not ok
          collect iteration_history
          update iteration_best if objective improved
     d) if iteration_best better than global best:
          update global best; no_improve_count <- 0
        else:
          no_improve_count <- no_improve_count + 1
     e) update_pheromone(...)
     f) advance_beta_schedule(...)
     g) if no_improve_count >= no_improve_max: break
6) return state.best_solution

3.2.3 路径构建（转移规则）核心细节问答

代码锚点：src/spd/aco_alns.py::construct_ant_solution（含局部函数 transition_stats 与 roulette_select）。

Q1: \(\eta_{ij}\) 完整公式？

代码实现公式： \[ \eta_{ij}

\max\left( 10^{-9}, w_{dist}\cdot \eta^{dist}_{ij} + w_{tw}\cdot \eta^{tw}_{ij} + w_{cap}\cdot \eta^{cap}_{ij} \right) \] 其中： \[ \eta^{dist}_{ij}=\frac{1}{1+d_{ij}/\bar d} \] \[ \eta^{tw}_{ij}=\mathrm{clip01}\left(\frac{l_j-a_j}{T_h}\right) \] \[ \eta^{cap}_{ij}=\mathrm{clip01}\left(\frac{Q_T-\hat \ell_j}{Q_T}\right) \] 符号说明：

  • \(d_{ij}\)：卡车路网距离 instance.truck_distance_km[(i,j)]（不是欧氏距离）
  • \(\bar d\)：当前候选集平均距离 dist_scale
  • \(l_j\)：客户 latest
  • \(a_j\)：若从当前状态转移到 j 的预计到达时间
  • \(T_h\)：时间域长度 depot_latest - depot_earliest
  • \(Q_T\)：卡车容量（不是无人机容量）
  • \(\hat \ell_j\)：服务 j 后卡车投影载重
  • clip01(x)=min(1,max(0,x))

Q2: 轮盘赌是纯概率还是贪婪混合？

代码实现：纯概率轮盘赌，不含 q0 贪婪分支。 证据：roulette_select 仅按累计概率采样。 结论：未找到 ACS 风格 q0 参数；原因：代码中无该变量、无 if rand<q0 then argmax 分支。

Q3: 受限候选列表定义、k 取值、扩大邻域触发？

候选列表构建：

\[ candidate\_size=\min\left(remaining,\ \max(10,\min(25, round(4\sqrt{remaining})))\right) \]

  • 2. 取前 candidate_size 构成 near list。

  • 若 params.aco.candidate_list_size 配置存在：取该值
  • 否则动态默认：

3.2.4 信息素更新机制完整展开

代码锚点：src/spd/aco_alns.py::update_pheromone。

Step 1 全局蒸发： \[ \tau_{ij}\leftarrow \mathrm{clip}\left((1-\rho)\tau_{ij},\tau_{\min},\tau_{\max}\right),\ \forall(i,j) \] 变量：evaporation_rate。

Step 2 迭代最优沉积： 对 iteration-best 解经过弧集合 \(\mathcal{E}_{iter}\)： \[ \Delta\tau_{iter}

\frac{Q_{aco}}{Z_{iter}} \] \[ \tau_{ij}\leftarrow \mathrm{clip}(\tau_{ij}+\Delta\tau_{iter},\tau_{\min},\tau_{\max}),\ (i,j)\in\mathcal{E}_{iter} \] 不是对所有蚂蚁解沉积，只对 iteration-best 与 global-best 两条轨道沉积。

Step 3 全局最优加权沉积： 对 global-best 弧集合 \(\mathcal{E}_{global}\)： \[ \Delta\tau_{global}

\omega_g\frac{Q_{aco}}{Z_{global}} \] \[ \tau_{ij}\leftarrow \mathrm{clip}(\tau_{ij}+\Delta\tau_{global},\tau_{\min},\tau_{\max}),\ (i,j)\in\mathcal{E}_{global} \]

Step 4 裁剪：每次更新后 clip 到边界。

默认值与变量名：

  • \(\rho\)：params.aco.evaporation_rate，config_small=0.2
  • \(\omega_g\)：params.aco.global_best_weight，config_small=0.65（函数中缺省回退 0.6）
  • \(\tau_{\min}, \tau_{\max}\)：来自 _resolve_tau_bounds，可配置或按 \(\tau_0\) 推导，不是迭代动态学习变量。

3.3.1 ALNS 主循环伪代码（完整版）

代码锚点：src/spd/aco_alns.py::ALNSOptimizer.optimize。

Input: initial_solution, params, home_status, global_best_objective
1) current_solution <- deepcopy(initial_solution)
2) current_beta <- params.beta_schedule.beta_init
3) current_objective <- compute_objective(..., time_window_penalty=current_beta)
4) best_local <- current_solution
5) initialize destroy_weights/repair_weights = operator_weight_init
6) temperature <- sa_initial_temperature

7) for iteration in range(params.alns.iterations):
     a) destroy_idx <- roulette_select(destroy_weights)
     b) repair_idx <- roulette_select(repair_weights)
     c) remove_count <- randint(remove_count_min, remove_count_max)
     d) destroy_result <- destroy_op(current_solution, remove_count)
     e) new_solution <- repair_op(destroy_result)

     f) if has_unserved OR has_damaged_sortie:
          _fallback_rebuild(new_solution)

     g) if cross_group_frequency triggered:
          new_solution <- random cross_group_operator(new_solution)

     h) if not _structural_and_physical_check(new_solution):
          treat as invalid candidate
          reward <- 0
          update selected weights with reward
          cool temperature
          record history
          continue

     i) new_objective <- compute_objective(..., time_window_penalty=current_beta)
     j) delta <- new_objective - current_objective
     k) if delta < 0:
          accept <- True
          reward <- reward_global_best or reward_improve
        else:
          sa_prob <- exp(-delta/temperature)
          accept <- (rand < sa_prob)
          reward <- reward_accept_worse if accepted else 0

     l) if accept:
          current_solution <- new_solution
          current_objective <- new_objective
          if current_solution hard-feasible and better:
               best_local <- current_solution

     m) update selected destroy/repair weights
     n) temperature <- temperature * sa_cooling_rate
     o) record history

8) return best_local

  • ACO 外层使用 ALNS 输出的 refined solution/objective 来调用 update_pheromone。

3.4 邻域算子设计（D1-D4, R1-R3, Cross-group）

D1 Random Removal

函数名：d1_random_removal（文件：src/spd/aco_alns.py） 类型：Destroy 操作对象：卡车路径与无人机 sortie（通过统一移除函数）

操作定义： Step 1: 收集 solution.all_customers。 Step 2: 计算 \(k=\mathrm{clamp}(remove\_count,0,|customers|)\)。 Step 3: 用 rng.sample(customers,k) 抽样。 Step 4: 对每个移除客户调用 _remove_customer_in_place，将其加入 unserved_customers。

关键参数：

  • 移除数量 \(q\)：变量 remove_count，范围由外层 remove_count_min ~ remove_count_max 给出。
  • 随机源：rng（来自 ALNS 主循环中的 random_state）。

选择逻辑：

  • 无评分函数。
  • 概率性选择，均匀无放回采样。
  • 随机性来源：Python random.Random.sample。

随机环境设计（概率性算子字段）：

  • 分布类型：离散均匀组合采样（无显式参数化正态/泊松）。
  • 代码变量：rng.sample(...)。

触发条件（权重增加）：

  • 该算子被选中且候选解达到奖励条件（全局改进/局部改进/接受劣解）时，因 reward>0 而更新权重。

建议图示：是。图示内容：移除前后客户分配对比。

D2 Worst Removal

函数名：d2_worst_removal（文件：src/spd/aco_alns.py） 类型：Destroy 操作对象：卡车路径与无人机 sortie

操作定义： Step 1: 计算 baseline compute_objective(solution)。 Step 2: 对每个客户 \(c\)，构造“仅删除 c”的候选解。 Step 3: 计算 improvement = baseline - candidate_obj。 Step 4: 按 improvement 降序排序，取前 \(q\) 个。 Step 5: 统一删除这 \(q\) 个客户。

关键参数：

  • 移除数量 \(q\)：同上。
  • 评分值：improvement。

选择逻辑（完整公式）： \[ score(c)=Z(S)-Z(S\setminus\{c\}) \]

  • 确定性选择：按 score 排序取 Top-q。
  • 若单删候选不可计算，记为 \(-\infty\)。

随机环境设计：

  • 非概率排序，不使用显式随机分布（除 ties 的 customer_id 次序规则）。

触发条件（权重增加）：同 D1。

建议图示：是。图示内容：边际贡献排序柱状图。

D3 Related Removal

函数名：d3_related_removal（文件：src/spd/aco_alns.py） 类型：Destroy 操作对象：客户集合（间接作用于 route/sortie）

操作定义： Step 1: 从客户集中随机选择 seed。 Step 2: 计算其他客户到 seed 的几何距离（欧氏）并升序排序。 Step 3: 删除 seed + 最近的(k-1)个客户。 Step 4: 构建部分解。

关键参数：

  • \(q\)：移除数量。
  • 距离度量：hypot(x_i-x_seed,y_i-y_seed)。

3.5 SA 接受准则与自适应权重更新

3.5.1 SA 接受准则

代码锚点：src/spd/aco_alns.py::ALNSOptimizer.optimize。

接受概率公式： \[ \Delta = Z_{new}-Z_{cur} \] \[ P_{accept}= \begin{cases} 1, & \Delta<0\\ \exp\left(-\frac{\Delta}{T}\right), & \Delta\ge 0 \end{cases} \] 代码实现：if delta < 0: accept=True else sa_probability = exp(-delta/T); accept = rand < sa_probability。

温度参数：

\[ T\leftarrow \max(T\cdot \alpha,\ 10^{-9}) \] 其中 \(\alpha=\texttt{params.alns.sa\_cooling\_rate}\)，config_small=0.98。

  • 初始温度 \(T_0\)：params.alns.sa_initial_temperature（config_small=100.0）
  • 冷却方式：几何冷却
  • \(T_{min}\)：未找到独立参数变量；代码下界硬编码为 1e-9。

3.5.2 自适应权重更新

代码锚点：src/spd/aco_alns.py::ALNSOptimizer.optimize（行 1255-1262）。

奖励类别与默认值（config_small）：

  • \(\sigma_1\)（新全局最优）：reward_global_best=33.0
  • \(\sigma_2\)（改进但非新全局最优）：reward_improve=13.0
  • \(\sigma_3\)（接受劣解）：reward_accept_worse=9.0
  • 拒绝/无效候选：reward=0

反应因子：

  • 参数名：reaction_factor，config_small=0.1

更新公式（destroy 与 repair 选中算子分别更新）： \[ w \leftarrow (1-r)w + r\cdot reward \] 其中 \(r=\texttt{reaction\_factor}\)。

更新频率：

  • 每次 ALNS 迭代更新一次（非 segment 式）。
  • 仅更新本次被选中的 destroy_idx 与 repair_idx。

3.6 终止条件与算法复杂度

3.6.1 终止条件（逐条，含变量名）

代码锚点：src/spd/aco_alns.py::ACOALNSSolver.solve、ALNSOptimizer.optimize。

  • 1. ACO 外层最大迭代：
  • 变量：params.aco.max_iterations
  • 示例默认：20（config_small）
  • 2. ACO 无改进提前停止：
  • 变量：params.aco.no_improve_max
  • 条件：no_improve_count >= no_improve_max
  • 示例默认：15（config_small）
  • 3. ALNS 内层固定迭代结束：
  • 变量：params.alns.iterations
  • 示例默认：50（config_small）

说明：ALNS 内层无“温度阈值停止”参数，按固定迭代执行。

3.6.2 时间复杂度分析

设：

  • \(I\)：ACO 外层迭代数
  • \(A\)：每轮蚂蚁数
  • \(L\)：ALNS 内层迭代数
  • \(N\)：客户数

总复杂度可分解为： \[ \mathcal{O}\left( I\cdot A\cdot\left(C_{construct}(N)+C_{alns}(L,N)\right) + I\cdot C_{pheromone}(N) \right) \]

其中：

  • construct_ant_solution 主成本来自候选评估与可行性估计；
  • ALNSOptimizer.optimize 主成本来自候选生成、可行性检查、目标函数计算与 fallback 重建；
  • update_pheromone 主成本与 pheromone 边规模线性相关。

3.6.3 并行实现

代码锚点：src/spd/aco_alns.py::ACOALNSSolver.solve。

并行粒度：蚂蚁级并行（ant-level parallelism）。 实现：multiprocessing + spawn + pool.map(_run_single_ant, ant_args_list)。 worker 数：min(ant_count, max(1, cpu_count-1))。 失败退化：并行异常时自动回退串行执行本轮。

3.8 伪代码（Algorithm2e 格式）

Algorithm 1: 整体算法主流程（ACO + ALNS 嵌套）

\begin{algorithm}[H]
\caption{Offline ACO-ALNS Main Procedure}
\KwIn{instance, params, rng}
\KwOut{best feasible offline solution}
home\_status $\leftarrow$ all customers set to True\;
S0 $\leftarrow$ ETPRC.build\_initial\_solution(instance, params, rng)\;
Z0 $\leftarrow$ compute\_objective(S0, beta\_init)\;
initialize pheromone matrix $\tau$\;
best $\leftarrow$ (S0, Z0)\;
noImprove $\leftarrow 0$\;
\For{$iter=1$ \KwTo $I_{max}$}{
  build ant argument list\;
  \eIf{parallel pool available}{
    run all ants by pool.map(\_run\_single\_ant)\;
  }{
    run all ants serially\;
  }
  select iteration-best ant result\;
  \If{iteration-best improves global best}{
    update global best\;
    noImprove $\leftarrow 0$\;
  }\Else{
    noImprove $\leftarrow$ noImprove + 1\;
  }
  update\_pheromone(state, iteration-best, global-best)\;
  advance\_beta\_schedule(state)\;
  \If{noImprove $\ge$ no\_improve\_max}{break\;}
}
\Return global best solution\;
\end{algorithm}

Algorithm 2: ACO 路径构建（含 \(\eta\) 计算、轮盘赌、fallback）

\begin{algorithm}[H]
\caption{ACO Ant Construction with Candidate Expansion and Fallback}
\KwIn{instance, params, state.pheromone, rng}
\KwOut{candidate solution}
groups $\leftarrow$ ETPRC.\_customer\_grouping(...)\;
\ForEach{group}{
  initialize route=[depot], remaining=group, current\_time, current\_load\;
  \While{remaining not empty}{
    sorted\_candidates $\leftarrow$ remaining sorted by truck distance\;
    near\_candidates $\leftarrow$ first k candidates\;
    evaluate transition\_stats on near\_candidates\;
    \eIf{feasible candidates exist in near list}{
      selection\_pool $\leftarrow$ feasible near candidates\;
    }{
      expand to full sorted\_candidates and re-evaluate\;
      \eIf{expanded feasible exists}{
        selection\_pool $\leftarrow$ expanded feasible\;
      }{
        selection\_pool $\leftarrow$ near (or full) candidates with fallback weights\;
      }
    }
    next $\leftarrow$ roulette\_select(selection\_pool, weights)\;
    append next to route and update time/load\;
  }
  append depot to route\;
  \eIf{extract sortie succeeds}{
    keep updated route/sorties\;
  }{
    fallback route $\leftarrow$ ETPRC.\_build\_truck\_route(...)\;
    extract sorties from fallback route\;
  }
}
assemble full candidate solution\;
\If{candidate has unserved customers}{
  \Return ETPRC.build\_initial\_solution(...)\;
}
\Return candidate\;
\end{algorithm}

Algorithm 3: 信息素更新

\begin{algorithm}[H]
\caption{Pheromone Evaporation and Dual Deposit Update}
\KwIn{state.pheromone, iteration-best, global-best, params}
\KwOut{updated state.pheromone}
resolve $(\tau_{min}, \tau_{max})$\;
\ForEach{edge in pheromone}{
  $\tau(edge) \leftarrow clip(\tau(edge)\cdot(1-\rho), \tau_{min}, \tau_{max})$\;
}
compute $\Delta_{iter} = Q_{aco}/Z_{iter}$ if iteration-best valid\;
deposit $\Delta_{iter}$ on edges of iteration-best route\;
compute $\Delta_{global} = \omega_g \cdot Q_{aco}/Z_{global}$ if global-best valid\;
deposit $\Delta_{global}$ on edges of global-best route\;
clip all touched values into $[\tau_{min}, \tau_{max}]$\;
\Return updated pheromone\;
\end{algorithm}

Algorithm 4: ALNS 内层循环（含可行性处理完整分支）

\begin{algorithm}[H]
\caption{ALNS Inner Loop with Fallback and SA Acceptance}
\KwIn{initial solution, params, home\_status, global\_best\_objective}
\KwOut{best\_local feasible solution}
initialize current solution/objective, best\_local, temperature, operator weights\;
\For{$it=1$ \KwTo $N_{alns}$}{
  select destroy and repair by roulette over weights\;
  sample remove\_count in [q\_min, q\_max]\;
  partial $\leftarrow$ destroy(current)\;
  candidate $\leftarrow$ repair(partial)\;
  \If{candidate has unserved OR damaged sortie structure}{
    fallback\_rebuild(candidate)\;
  }
  \If{cross-group frequency condition holds}{
    candidate $\leftarrow$ random cross-group operator(candidate)\;
  }
  \If{structural\_and\_physical\_check(candidate) fails}{
    reward $\leftarrow 0$\;
    update selected weights\;
    cool temperature\;
    record history\;
    continue\;
  }
  newObj $\leftarrow$ compute\_objective(candidate)\;
  $\Delta \leftarrow$ newObj - currentObj\;
  \uIf{$\Delta<0$}{
    accept\;
    reward $\leftarrow \sigma_1$ or $\sigma_2$\;
  }\Else{
    accept with probability $\exp(-\Delta/T)$\;
    reward $\leftarrow \sigma_3$ if accepted else 0\;
  }
  \If{accepted}{
    current $\leftarrow$ candidate\;
    \If{current is hard-feasible and better than best\_local}{
      best\_local $\leftarrow$ current\;
    }
  }
  update selected weights\;
  cool temperature\;
  record history\;
}
\Return best\_local\;
\end{algorithm}

Algorithm 5: 自适应权重更新

\begin{algorithm}[H]
\caption{Adaptive Weight Update for Selected Operators}
\KwIn{$w_d, w_r, reward, reaction\_factor$}
\KwOut{$w_d', w_r'$}
$w_d' \leftarrow (1-r)\cdot w_d + r\cdot reward$\;
$w_r' \leftarrow (1-r)\cdot w_r + r\cdot reward$\;
\Return $(w_d', w_r')$\;
\end{algorithm}
